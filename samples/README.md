# 样本目录说明

本目录存放开发/测试用的本地样本。**除本说明文件外，目录内容一律不入库**（`.gitignore` 已排除）。

> 注意：凡是从本机游戏或本机样本派生出来的内容，都不要提交到仓库，
> 也不要在这里登记文件名、体积或来源。

## 什么入库、什么不入库

| 内容 | 入库 | 为什么 |
|---|---|---|
| `README.md`（本文件） | ✅ | 说明文档 |
| `saves/`（角色存档） | ❌ | 个人数据 |
| `sidecar/`、`archives/`、`work/` | ❌ | 个人数据 / 临时副本 |
| `game-data/` | ❌ | 由本机数据生成，只在本机使用 |

## 目录结构

```text
samples/
├── README.md            # 本文件（入库）
├── saves/
│   ├── d2r-105/         # 存档版本 105（D2R 3.x）
│   └── d2r-legacy/      # 旧存档版本（版本 99）
├── sidecar/             # 游戏加载器与 mod 的旁车文件
├── game-data/           # 程序运行所需的本地数据（由 tools/fetch-data.ps1 生成）
│   ├── excel/           #   数据表
│   └── lng/strings/     #   文本表
├── work/                # 临时工作副本（改动前后对照等，可随时删）
└── archives/            # 原始备份压缩包
```

## 换机怎么把数据弄回来

程序运行需要的数据**不进仓库、也不随仓库分发**，而是每台机器本地准备：

```powershell
pwsh -File tools/fetch-data.ps1       # 从本机游戏目录导出到 samples/game-data/
python tools/local-stats.py           # 只统计数量与体积（产物不入库），确认数据齐不齐
```

导出完成后可以直接打包，数据会在构建时被内嵌进可执行文件：

```powershell
pwsh -File tools/package.ps1
```

**存档样本（`saves/`、`sidecar/`、`archives/`）无法自动重放**，需要时从本机存档目录或备份压缩包复制回来。

## 使用约定

- 样本仅本地使用，**不要提交进 git**；提交前请确认 `git status` 里没有 `samples/` 下的新文件。
- 任何写路径测试都先复制样本到临时目录，禁止直接改样本原件。
- 不要在本文件或其他会入库的文档里登记样本的来源、文件名或体积。

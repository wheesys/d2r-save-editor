# D2R 存档修改器

暗黑破坏神2：重制版（Diablo II: Resurrected）**单机存档**修改器。
Windows 桌面程序，图形界面，不联网、不接触战网 / 任何在线服务。

> **当前版本 0.0.1 — 功能可用，但仍属早期版本。**
> 主要在我自己的存档上验证，**覆盖面有限**。改存档前请自己留一份备份，
> 遇到问题按下面[「提交问题」](#提交问题)一节反馈。

---

## 下载与运行

在 [Releases](../../releases) 页下载最新的 `D2RSaveEditor-<版本>-win-x64.exe`。

- **单文件，免安装**：双击即用，不需要装 .NET、不需要游戏、不需要别的工具
- **会请求管理员权限**：存档通常在受保护目录（`C:\Users\<你>\Saved Games\Diablo II Resurrected`），
  没有管理员权限改不了。程序启动时系统会弹 UAC，点「是」即可
- 需要 Windows 10 / 11（依赖系统自带的 WebView2 运行时，Win11 及较新的 Win10 已内置）

## 怎么用

### 1. 打开存档

点左上角**「打开存档…」**，选中要改的 `.d2s` 文件。

- 程序会**记住上次打开的路径**，下次启动可以直接从「打开存档…」里选
- **不会自动打开任何存档**：启动后是空白界面，避免手抖改错文件
- 也支持共享储物箱 `.d2i`

打开后顶部会显示存档路径、角色名、数据集状态。

### 2. 五个页签

| 页签 | 能做什么 |
|---|---|
| **角色** | 等级、力量/敏捷/体力/精力、金币等基础属性；属性点与技能点 |
| **技能** | 各技能等级、技能点（能看到每个职业的三系技能树） |
| **任务** | 三个难度的任务完成情况、传送点（小站）开通情况 |
| **物品栏** | 容器网格视图：装备位、背包、方块、箱子、腰带 |
| **佣兵** | 佣兵的装备 |

### 3. 改物品

在**物品栏**页点物品块（或用拖拽挪格子），弹出的窗口里可以：

- 改**孔数、当前耐久、堆叠数量、防御**
- 看每一行属性的**有效范围**，直接改值；带参数的属性有**两个值**（值1 / 值2）
- **新增属性**：先在上方搜索框里搜（中文名或内部名都能搜），选中后填值再点「添加」
- **删除**某一条属性
- 改物品在容器里的位置

操作提示：

- **拖拽**物品块可以换格子或换容器（背包 ⇄ 箱子 ⇄ 方块）
- 物品属性窗口用**右键**打开（左键留给拖拽）
- 属性值**改完点别处就生效**，不需要额外确认
- 说明里的「值1 / 值2」就是这条属性能改的两个数；`值2` 决定"哪个职业的技能等级""哪个光环"这类参数

### 4. 保存

改动是立即生效到内存里的，**点顶部「保存」才会写入文件**。

- 保存时会先做**完整校验**：写出 → 重新解析 → 比对角色信息与尾随数据，通过才落盘
- 覆盖原文件前会**自动备份**成 `你的存档.d2s.bak`；
  如果该名字已存在，会依次用 `.2.bak`、`.3.bak`…**不会覆盖你之前的备份**
- 校验不通过时**原文件一个字节都不会动**
- 不想保存就点**「放弃修改」**，重新从磁盘读取

## 当前版本的测试情况

**已实际验证过的**：

- 存档读取 → 写出**逐字节一致**（这是所有编辑功能的地基）
- 角色属性、技能等级、任务、传送点的读取与修改
- 物品明细的读取与修改（含带参数的属性，即"值1 / 值2"）
- 物品在容器里的拖拽移动
- 保存前的校验与自动备份

**说明与限制**：

- **只支持当前版本的存档**。旧版本存档（D2R 早期版本、原版 D2 存档）**没有测试过**，
  不保证能打开，更不保证改了之后游戏能读
- **佣兵的换装 / 卸下**还没做完（可以看，不能换）
- **Mod 支持不完整**：不同 Mod 的背包/箱子尺寸、自制物品都可能无法正确显示
  （程序会让你确认容器尺寸和佣兵是否全装备）
- 极少数属性（例如 `item_regenstamina_bytime`）的数值含义还没搞清楚，
  显示出来可能不是你预期的数
- 有一件存档的条目段与原文有 2 字节差异，仍在排查
- 程序不联网，**不会自动检查更新**

## 提交问题

请在 [Issues](../../issues) 里反馈。为了能定位问题，**请尽量附上这些内容**：

| 需要 | 说明 |
|---|---|
| **版本号** | 界面顶部或 exe 文件名里的 `0.0.1` |
| **问题描述** | 你做了什么操作、期望什么结果、实际发生了什么 |
| **复现步骤** | 越具体越好（点了哪个页签、哪个物品、填了什么值） |
| **报错原文** | 界面上的红色提示文字，**原文照抄**，不要只写"报错了" |
| **截图** | 有截图基本能省一半时间 |

**如果你愿意提供存档文件，能极大加快定位**（尤其"某个物品显示不对"这类）：

- 附上**出问题的存档**，并说明是**哪一件物品 / 哪一条属性**有问题
- 如果可能，说明**游戏里实际显示的是什么**——这能帮我判断是读错还是显示错
- ⚠️ 存档里有你的角色名、进度等信息，**自己判断是否愿意公开**。
  也可以只描述数值、不发文件
